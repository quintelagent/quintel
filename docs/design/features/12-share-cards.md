# 12 · Share cards (OG images)

**Flags:** RUN_SHARE_CARDS (run + briefing), POSITION_SHARE_CARDS ("My NVDA odds"), Pro scenario cards need PRO_TIERS too · **Phase:** P1 launch-day drop · **Location:** "Share" buttons in hero, briefings, My position, Pro custom runs; images generated by the Worker

## Purpose
Every result can become a clean 1200×630 image that looks like Quintel on X, Telegram and iMessage.

## Image template (all four types)
- Background `--paper`, 64px padding, no gradients.
- Top-left: PixelMark + "quintel".
- Left column: eyebrow (mono, `--ink-2`), big number (mono, ~150px), label (sans 40px), timestamp "Run 4,182 · Nov 24, 10:40am ET".
- Right: PixelField ~460px square from that run.
- Bottom strip (mono 22px, `--ink-2`): "Scenario odds, not advice · quintelagent.com".
- Text never touches the edges; works when cropped to a square (X mobile).

| Type | Eyebrow | Big number + label |
|---|---|---|
| Run | "Does it hold?" | "61.2%" · "of 1,000,000 futures keep Monday's gain" |
| Briefing | "Briefing · {time} ET" | headline (2 lines max) + odds change "+0.4 pts" |
| My NVDA odds | "My odds" | "54.3%" · "odds of profit in 1 week" · entry shown as "Entry hidden" by default |
| Pro scenario | inverted "Pro" pill | "22.4%" · "odds of $160 or lower by Dec 31" |

## Share UI (ShareSheet)
Phone: bottom Sheet with image preview, buttons "Share" (navigator.share), "Copy link", "Download image". Laptop: centered dialog, same buttons + "Post on X".
My NVDA odds only: toggle "Show entry price" (off by default). Amounts and shares are never on the image.

## States
- **Generating:** preview Skeleton at 1200:630.
- **Failed:** "Couldn't make the image. Copy the link instead." (link still works with the default og.png).
- **Flag off:** Share buttons hidden.

## Data and privacy
Images are generated from run IDs, never from personal data. Position images encode only odds + horizon (+ entry if the toggle is on) in the URL.

## Reuses
ShareCard, ShareSheet, Sheet, PixelField, PixelMark, Pill, Button, Skeleton.
